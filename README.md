## 名詞表

| 名詞 | 定義 |
|---|---|
| 特護 | 特別護理師：自費一對一照護的護理師（醫院陪病或居家） |
| 個案 Case | 一位病人的一段服務關係（含需求、地點、方案） |
| 服務單 | 個案下的一段服務期間與計價方案 |
| 班次 Shift | 派單與打卡的最小單位（預設 12 小時） |
| 交班 Handoff | 上一班向下一班的結構化交接（ISBAR） |
| A/B/C 層 | 警報引擎三層：絕對臨界值／早期預警評分／個人基準線（平均線） |
| 質性紅旗 | 不經數值判斷、直通紅色警報的臨床徵象（如咖啡渣樣嘔吐物） |
