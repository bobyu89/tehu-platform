# ADR-005：衛教媒體資產以 ID 綁定，模型不得生成連結

- 日期：2026-08-12｜狀態：採納（承襲衛教機器人 PRO MAX 原設計原則）

## 脈絡
衛教模組會推送圖卡、影片、語音給家屬。LLM 若自行輸出檔名或 URL，就有幻覺連結與未審核素材外流的風險。政府開放授權素材另有「不得惡意變更」條款——展示與原素材不符的資訊有法律責任。

## 決策
模型只能輸出媒體資產 ID（如 `NG-003-VIDEO`）；應用層以 media-index 對照表解析為實際檔案。無效 ID 一律攔截。知識庫回答強制引用 unit 來源並經引用驗證（移植 governance 機制）。

## 理由
1. 送出的每一份素材保證經過審核——信任與法遵的底線
2. 素材更新只改對照表，不動 prompt 與知識庫
3. groundedness 在開放授權條款下**是法律要求，不只是品質指標**

## 後果
- 需維護 media-index 與資產上架流程（上傳→審核→發 ID）
- 12 支自製教學影片為首批資產（著作權乾淨）；外部素材逐項確認授權後才入庫
